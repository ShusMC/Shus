# Shus Client

Shus Client is a third-party Minecraft Java Edition launcher for Windows, built using Electron.

## Features
- Minecraft version and instance management
- Modrinth mod and resource pack browsing
- Launcher themes
- Microsoft account integration (under development)
- Multiple account management (planned)

## Development Status
Shus Client is currently in alpha development. Minecraft Java Edition authentication requires approval for access to the official game service APIs.

Shus Client does not collect Microsoft account passwords.
